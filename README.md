# asm

Assembly Language Source Code in System Programming Lecture

## files
- asm.bat : assembler batch file - assemle(ml) and link  \
   usage : C> asm *asmfile*  \
(assume that source code: *asmfile*.asm)
- print.inc : an include file for some print procedures
- print.lib : a library file for some print procecures
- Project19.zip : compressed project file for Visual Studio 2019 
- Project22.zip : compressed project file for Visual Studio 2022 \
(assume that print.inc and print.lib exist in c:\asm)
